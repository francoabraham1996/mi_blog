# Mi Blog - Proyecto Final Django

Proyecto final desarrollado con **Python y Django**.

El sitio consiste en un blog donde los usuarios pueden registrarse, iniciar sesión, crear artículos y administrar sus propias publicaciones.

---

## Funcionalidades

El proyecto incluye:

- Registro de usuarios.
- Inicio y cierre de sesión.
- Perfiles de usuario editables.
- Creación de artículos.
- Visualización de artículos.
- Edición de artículos.
- Eliminación de artículos.
- Control para que cada usuario pueda editar y eliminar solamente sus propios artículos.
- Buscador de artículos por título.
- Página "Acerca de mí".
- Página de contacto.
- Formulario de contacto.
- Administración de artículos, perfiles y mensajes desde Django Admin.
- Grupos y permisos de usuarios.
- Grupo "Autores".
- Herencia de templates mediante `base.html`.
- Bootstrap para el diseño del sitio.
- CSS propio mediante archivos estáticos.
- Tests básicos del proyecto.
